# Products Name Cleaner

商品名称清洗与标准化工具。

## 功能

- 上传 Excel 商品名称文件
- 清理商品名称中的多余符号和空格
- 统一部分品牌别名
- 生成标准化商品名称
- 查找相似商品名称，供人工审核
- 导出 Excel 结果

## 输入文件

上传 `.xlsx` 格式的 Excel 文件。

文件中需要包含一列商品名称。

## 输出结果

程序会生成一个 Excel 文件，包含三个工作表：

1. 标准商品库
2. 原始名称映射表
3. 相似名称审核
